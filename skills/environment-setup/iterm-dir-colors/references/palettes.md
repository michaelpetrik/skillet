# Dark palette presets

Use these preset names with `--color`:

- `ember`: warm dark red, `#3f2629`
- `wine`: muted burgundy, `#4a2434`
- `rust`: dark brick red, `#5a2f24`
- `crimson`: deeper red-brown, `#58232c`
- `aubergine`: dark plum, `#44263f`
- `forest`: dark green, `#243a2d`
- `ocean`: dark blue-teal, `#213947`
- `slate`: dark graphite blue, `#2d3342`

All presets are biased toward darker backgrounds with light foreground text.
